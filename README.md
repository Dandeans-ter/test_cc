# test_cc

Repositório de teste criado para experimentar fluxos de trabalho com o [Claude Code](https://claude.com/claude-code).

## Sobre

Este projeto ainda está em fase inicial e, por enquanto, contém apenas este README. Novos arquivos e funcionalidades serão adicionados conforme o projeto evoluir.

## Como começar

Clone o repositório:

```bash
git clone https://github.com/Dandeans-ter/test_cc.git
cd test_cc
```

## Estrutura

```
test_cc/
└── README.md
```

## Contribuindo

1. Crie uma branch para sua alteração: `git checkout -b minha-alteracao`
2. Faça o commit das mudanças: `git commit -m "Descrição da alteração"`
3. Envie a branch: `git push origin minha-alteracao`
4. Abra um Pull Request
